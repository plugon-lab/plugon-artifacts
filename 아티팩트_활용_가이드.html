아티팩트 활용 가이드

클로드 챗 실습 중 화면 오른쪽에 뜨는 결과물, "아티팩트"를 다루는 법을 정리했습니다.

1

아티팩트란?

  • 클로드가 채팅 답변과 별도로 만들어서, 화면 오른쪽 전용 창에 띄워주는 결과물입니다
  • 문서, 코드, 웹페이지처럼 독립적으로 완결된 콘텐츠일 때 만들어집니다
  • 대화를 닫아도 남고, 링크로 공유하거나 파일로 다운로드할 수 있습니다
대화창
보고 문서로 정리해줘
오른쪽에 문서를 만들었어요
아티팩트

대화창 옆, 별도 창에 뜨는 것이 아티팩트입니다

2

아티팩트, 두 가지 형식

  • 클로드가 아티팩트를 만들 때 보통 md(마크다운) 또는 html 두 형식 중 하나를 씁니다
  • 형식에 따라 수정하는 방법이 달라집니다
구분 md (마크다운) html
화면 모습 글자와 구조 위주의 문서 색·표·레이아웃이 입혀진 완성된 화면
부분 수정 (드래그) 가능 불가능
수정 방법 텍스트 드래그 → 콕 집어 수정 요청 대화창에 말로 수정 요청
다운로드 가능 가능
링크 공유 가능 가능
📝 참고 — 형식은 보통 클로드가 알아서 고릅니다. 부분 수정을 하고 싶다면 프롬프트에 "마크다운(텍스트) 문서로 만들어줘"라고 명시하는 게 확실합니다.
3

md — 드래그로 콕 집어 수정하기

  1. 아티팩트 안의 텍스트를 원하는 만큼 드래그해 선택합니다 (문장이나 문단 단위 추천)
  2. 선택하면 뜨는 버튼을 눌러 어떻게 고칠지 짧게 입력합니다
  3. 선택한 부분만 바뀌고, 나머지는 그대로 유지됩니다
PROMPT 복사
핵심 숫자가 먼저 오게 고쳐줘
더 짧게
격식 있게 바꿔줘
💡 팁 — 단어 몇 개만 애매하게 선택하면 클로드가 의도를 잘못 이해할 수 있습니다. 문장 단위로 선택하세요.
4

html — 대화창으로 수정 요청하기

  • html은 이미 화면으로 완성된 형태라 드래그 선택이 안 됩니다
  • 대신 대화창에 직접 요청하면 됩니다
PROMPT 복사
제목 색깔을 좀 더 진하게 바꿔줘
표 순서를 진척률 낮은 순으로 정렬해줘
맨 아래에 다음 주 계획 섹션 하나 추가해줘

요청할 때마다 클로드가 아티팩트 전체를 다시 만들어 새 버전으로 갱신합니다.

5

버전 관리 — 잘못 고쳐도 괜찮습니다

  • 수정할 때마다 버전이 쌓입니다 (버전 2, 버전 3 …)
  • 아티팩트 창 좌측 하단 버전 선택기에서 이전 버전으로 언제든 되돌아갈 수 있습니다
  • "잘못 고쳤다" 싶으면 지우지 말고 이전 버전으로 돌아가면 됩니다
6

최종본 활용하기

  • 다운로드 — 아티팩트 창 우측 하단 버튼으로 파일 저장 (md는 텍스트 파일로, html은 웹페이지 파일로)
  • 링크 공유 — 공유 버튼으로 링크 생성, 대화를 닫아도 링크는 유지됩니다
  • 복사 — 내용만 클립보드로 복사해서 다른 문서에 붙여넣기도 가능합니다
