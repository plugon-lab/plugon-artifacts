CLAUDE CODE · 초보자 핵심 개념

Claude Code, 이것만 알면 시작할 수 있다

Claude Code는 폴더 단위로 작업 범위가 정해집니다.
세 가지 개념만 이해하면, 헷갈리지 않고 바로 쓸 수 있어요.

개념 01 · 폴더가 곧 Claude의 작업 범위입니다

개념 02 · 프로젝트마다 Claude는 완전히 독립적입니다

개념 03 · 세션이 끝나면 Claude는 모든 것을 잊습니다 — CLAUDE.md가 해결책입니다

개념 01

폴더 = Claude의 세계

  • VS Code에서 폴더 열기 (File → Open Folder)
  • 그 폴더 안 파일만 Claude가 봄
  • 다른 프로젝트는 보이지 않음

💡 터미널에서는 cd 폴더명 후 claude 실행도 같은 원리입니다

개념 02

세션은 서로 독립적

  • 프로젝트마다 별도 Claude 세션
  • 두 세션의 대화는 섞이지 않음
  • 동시에 여러 프로젝트 진행 가능

💡 A 프로젝트에서 한 말이 B에선 전혀 영향 없음

개념 03

CLAUDE.md = 영구 기억

  • 세션 종료 시 대화 내용은 사라짐
  • CLAUDE.md에 규칙을 적어두면
  • 매 세션마다 자동으로 읽어옴

💡 "이 프로젝트 규칙서"라고 생각하면 됩니다
